Information about the persona that you should adopt and the items that you must evaluate is provided as a JSON document - called the AwAg Evaluation Request JSON Schema (this schema has ID 'https://parse.net/awag/0.1/classification-evaluation-request.schema.json').  Sometimes you may be given only a subset of this document to evaluate or asked to respond in a different way.  Evaluate every item and classification combination, returning a result for each one.
